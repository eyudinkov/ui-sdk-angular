# P0.2: TypeScript 6 in the catalog

The catalog's `typescript` moves from `~5.9.3` to `~6.0.3`, the only line `@angular/compiler-cli` 22.3 accepts (`>=6.0 <6.1`), and the five existing adapters pass every gate they passed before. This applies decision D6.

## Settled

- **Every workspace moves.** Each `package.json` takes `typescript` from the catalog, so one line moves the root, the six packages, both apps, the benchmarks, the tests and the examples. No workspace pins its own range.
- **TypeScript 7 stays where it is.** `typescript7` is still `7.0.2` for `scripts/tsgo.mjs`, which runs the plain type checks. The catalog's version serves the tools that use the JavaScript API: `vue-tsc`, `svelte-check`, the declaration build in `scripts/build/declarations.mjs`, `typescript-eslint`, and the scripts that import `typescript`.
- **The tools accept it.** Their installed peer ranges: `vue-tsc` 3.3.12 `>=5.0.0`, `svelte-check` 4.7.6 `^5.0.0 || ^6.0.0`, `typescript-eslint` 8.72.1 `>=4.8.4 <6.1.0`.
- **Fallback.** If a tool breaks later, the task that finds it stops and reports. The alternative in D6, TypeScript 6 for the Angular package, the playground and the examples only, is your decision, and no task takes it on its own.
