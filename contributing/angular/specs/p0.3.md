# P0.3: `packages/angular` skeleton and build script

`@ui-sdk/angular` is a workspace package with one entry, `primitive`, and `pnpm --filter @ui-sdk/angular build` compiles it with `ngc` in partial mode into the per-file `dist` the other adapters ship. This applies decisions D7 and D8.

## Settled

- **Entry map.** One entry. `./primitive` points at `./src/primitive.ts` in the repo, and at `./dist/primitive.js` with `./dist/primitive.d.ts` when published, `types` first. There is no root entry yet: U1 adds it.
- **A stub directive.** The entry exports `UiRoot`, a directive with the plan's selector and no behavior, so the build compiles a real directive. P1.3 writes the entry.
- **Peers.** `@angular/core` at `^22.0.0` and `@ui-sdk/core` at `workspace:^`, with nothing in `dependencies`. Development uses `@angular/core`, `@angular/compiler` and `@angular/compiler-cli` 22.3.0 from the catalog, and `rxjs`, which `@angular/core` takes as a peer.
- **`ngc` settings.** `angularCompilerOptions` in `tsconfig.json` sets `compilationMode: "partial"`, `strictTemplates`, `strictInjectionParameters` and `strictInputAccessModifiers`. The emit flags live in the build script, as they do in `declarations.mjs`: `--noEmit false --declaration --allowImportingTsExtensions false`, with `--rootDir src --outDir dist`.
- **No `experimentalDecorators`.** `ngc` type-checks and emits the same output with and without it, for a class decorator and for a legacy `@Input()`.
- **Private until Gate 3.** `"private": true` keeps the package out of `pnpm publish`, and out of changesets through `privatePackages.version: false`. `check-packages.mjs` now leaves a private package out. Task 3D.1 drops the flag when it adds the consumer and the peers.
- **No stability labels yet.** `check-code.mjs` flags `@stable` or `@experimental` on an export outside `documentedPackages`, which Angular joins in 3F.1. Until then an Angular export carries its JSDoc and no label.
- **No unit tests yet.** `packages/angular/test/` and the vitest setup arrive with P1.1's first tests, so the package has no `test` script for `pnpm --filter "./packages/*" test` to run.
